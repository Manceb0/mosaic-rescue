# README editorial artwork

Created 2026-09-24 using the built-in `image_gen` tool and the `imagegen` skill. These two original illustrations are NARRATIVE conceptual artwork, not scientific figures, patient observations, molecular structures or simulated experimental results. They live outside `figures/pub` to preserve that scientific figure registry.

## Direction

Apple-keynote-inspired restraint: warm white, translucent glass, soft shadows, teal and amber accents. No Apple trademarks or implied affiliation. Typography and all scientific claims remain editable Markdown. The images carry no experimental labels or numbers. Their interpretation is stated in README captions.

## Assets and inspection

- `mosaic-rescue-hero.png`: abstract genome → evidence layers → unfinished assembly. Inspected: no text, no patient data, no asserted biological outcome.
- `rescue-crossroads.png`: conceptual fork between restoration and tolerance. Inspected: no measured result; accompanying text explicitly leaves both outcomes open.

Tool outputs were copied unchanged into this project; no raster editing was performed. Generated artwork is not byte-reproducible by rerunning a prompt; the saved files are the selected deliverables. Scientific figures retain their separate deterministic renderers and QA.
